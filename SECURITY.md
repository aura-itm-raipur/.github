# Security Policy

## Supported Versions

We aim to address security issues in active public-facing projects and repository assets as quickly as possible.

## Reporting a Vulnerability

If you discover a security vulnerability, please email:

aura@itmuniversity.org

Include as much detail as possible, such as:

- A description of the issue
- Steps to reproduce it
- Affected files or components
- Any proof of concept, if available

Please do not open a public issue for security reports until the issue has been reviewed and coordinated privately.

## What to Expect

After receiving a report, we will review it, confirm the impact, and work on a fix or mitigation as needed.

We may follow up if additional information is required.
